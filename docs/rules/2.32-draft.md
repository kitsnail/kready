# kready 规则包 2.32（草案 v0.1）

## 一、适用条件

- 部署器：kubespray 2.32.x（基线哈希匹配 `configurator/baseline/2.32.0.sha256`）。
- 固定组合：Kubernetes **v1.36.4**（与 kubespray 2.32 一一对应，本团队策略）。
- 不满足时：基线不匹配 → 输出"无适用规则"，不判定。

## 七、不纳入（不做判定）

- 测试类：etcd fio、控制面重启演练、删除风暴 — 需要执行测试。
- 人工事实：网卡名、VIP、内网 DNS 地址 — 需人确认。
- 性能指标：WAL fsync p99、API p99 — 需长期监控。
- 对象规模：节点、Pod、CRD 数量 — 仅输出数值，不判定。
- GPU、Harbor — 暂无基线。

3. **OS 内核参数**：已裁定（D-017，2026-11-21）：纳入，OS-01～03 见 §六；规则条目与期望值按 B 类另行批准。
4. **SYS-04**：已决定为 `mode: info`，不判定。
5. **NODE-05**：已裁定（D-017，2026-11-21）：维持 `mode: info`，待有现场数据后再议（参考输入：scclabs-k8s-in-action `k8s/os/noupgrade.sh`、`k8s/os/nolinuxupgrades`）。
