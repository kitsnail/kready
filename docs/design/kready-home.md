# kready 本地目录标准

> 状态：已确认（用户决定，作为未来项目的标准）。
> 适用：所有 kready 的部署、配置、日志、报告与临时数据。

## 一、统一位置

所有 kready 相关文件统一放在一个目录下：

- 默认：`$HOME/.kready`（测试机 mlops-mc01 上为 `/root/.kready`）。
- 可由环境变量 `KREADY_HOME` 覆盖。

## 二、子目录

| 目录 | 用途 | 内容 |
|---|---|---|
| `bin/` | 可执行文件 | `kready` 二进制，按版本存放 |
| `config/` | 配置 | 不含任何凭据 |
| `logs/` | 运行日志 | 按日期滚动（标准已定，写入功能尚未实现） |
| `reports/` | 检查报告 | 每次 `check` 默认写入一份，文本或 JSON，与终端输出一致 |
| `snapshots/` | 快照 | `--live` 采集结果，每次一个时间戳目录，可用 `--snapshot` 复现判定 |
| `tmp/` | 临时文件 | 运行结束后清理 |

子目录名为项目标准，不得随意更改。

## 三、边界

- SSH 私钥与 `known_hosts` 仍在 `~/.ssh`，kubeconfig 仍在 `~/.kube`。不搬入 `KREADY_HOME`，不复制私钥。
- 工具不读取私钥内容，不输出凭据（见 ADR 0001）。

## 四、权限

- 新建的目录：`0700`。已存在的目录不改权限。
- 报告、快照、日志文件：`0600`，因为其中包含集群与节点信息。

## 五、默认写入行为

| 操作 | 写入位置 | 说明 |
|---|---|---|
| `check --snapshot` | `reports/check-<时间戳>.txt` 或 `.json` | 报告与终端输出一致 |
| `check --live` | `snapshots/<时间戳>/` 与 `reports/` | 先保存快照，再保存报告 |

- 时间戳为 UTC，格式 `20060102T150405Z`，可排序。
- 同一秒内多次运行，后续文件加序号后缀（`-2`、`-3`），不覆盖旧文件。

## 六、失败策略

- **目录不可用**（无法创建主目录或子目录）：判定前报错，退出码 2，不输出判定结果。避免用户误以为结果已存档。
- **报告或快照写入失败**（目录可用但写文件失败）：警告输出到 stderr，不改变判定结果与退出码。

## 七、路径代码

实现位于 `internal/home`，所有路径由此包统一生成，禁止在其它处硬编码 `.kready`。
