# 验收标准（acceptance）

> 维护者：人（产品经理）。Agent 只读取，不修改本文件。
> 作用：每个 REQ 的验收条目。Agent 按此实现与验证；人按此确认是否验收。

## 编写要求

- 每条标准可以自动判定，或可由人在真实环境中复核。
- 一条标准只描述一个结果，不写实现方式。
- 涉及规则判定的，写明规则 ID 与期望结论（正常 / 异常 / 未能确认）。

## 模板

```markdown
## REQ-000 <标题>

- [ ] 标准 1：<可判定的结果>
- [ ] 标准 2：<可判定的结果>

验收人：<人>　日期：<YYYY-MM-DD>
```
